PC 门店增长智能体

运行方式
1. 直接双击 index.html，或用浏览器打开。无需安装、无需联网、无需构建。
2. 首页是入口总览，五张卡片对应五个板块，点进去就走。
3. 第一次用先进「客户画像」，在左侧栏输入客户原话，选沟通渠道和本次目标，
   点「生成客户方案」会自动跳到右侧的画像编辑区；改完点「保存并应用画像」。
4. 顺序建议：客户画像 → 咨询中心 → 产品报价 → 行动计划 → 门店推广。

五个板块各做什么
- 01 客户画像：左侧栏输入客户原话，右侧生成 7 个可编辑字段（角色、需求、行为、态度、
  价位、系统路线、决策周期），保存后联动咨询、报价、介绍卡与交接留档。
- 02 咨询中心：输入客户问题得到逐项回答；右侧「本地资料补充」可上传 TXT / MD / CSV，
  传完点「用这些资料重新生成回答」，答复会优先用这份资料。下方「常见情境处理预设」
  是可折叠题库，31 条情境按开场/演示/价格/兼容/屏幕便携/竞品/售后/成交分 8 类，
  每条给「这样说」和「内部提醒」两栏，随当前产品与组合清单联动。
  这一页不依赖客户画像，随时可以直接用。
- 模型 API 接入：入口在右上角「API 接入」，任何页面都能点。默认收起，点开是悬浮窗，
  填 Chat Completions 地址、模型名、Key 三项，勾授权后「启用并测试接口」。
  接上后顶栏小圆点变绿、按钮文字变「API 已接入」。
  「开启思考模式」打开后，请求会带 reasoning_effort / thinking 参数，超时从 45 秒放宽到
  120 秒；服务商返回 reasoning_content（或 reasoning / thinking）时，答复上方会多一个
  可折叠的「模型思考过程」，取不到就整块不显示，不影响正式答复。
  密钥只存当前页面内存，刷新或点「清除配置」即失效。
- 03 产品报价：选类别 → 型号 → 配置 → 颜色后添加；手动录价并逐项勾选确认，才算入总额。
  组合折扣行默认隐藏，加到 2 件及以上才出现；退回 1 件会自动收起并清掉折扣，避免用
  一件商品套组合价。
  右侧「官方价格参考库」收录 141 条官方价格记录、65 个产品、6 个分组，按能否直接引用
  分三档：A 可购买页面价 / B 条件价与参考起价 / C 无公开金额。支持搜索、按分组、按档位
  筛选，一键填入报价单（填入后仍需人工勾选确认）。
- 04 行动计划：未来计划 + 反馈与交接两条路线。未来计划是四件事的竖排清单（今天 / 明天 /
  这周内 / 下次联系），每件都写「怎么做」和「可以直接说的一句话」，不再用五列表格。反馈与交接页自上而下是：产品组合介绍卡
  （居中单列，SVG / PNG 下载在卡下方，说明文字沉底）→ 执行记录与客户反馈 → 跟进人 →
  「保存并归档」→ 工作留档列表。
  每次保存都会追加一条新的留档，写明客户是谁、要什么、当前方案、价格状态、这次聊到哪，
  前一条不会被覆盖。留档在关掉网页前一直存在，除非手动点删除。换第二个客户重新生成
  画像再存一条，两条并列保留。没有画像时这一页会提示「请先完成客户画像」。
- 05 门店推广：填一张真实素材表单，本地生成小红书 / 公众号 / 朋友圈三平台草稿；
  封面区选版式后生成提示词，一键带到图片生成网站出图（需登录，网页版免下载）。

价格口径（重要）
- A 档可直接引用，但必须同时带款式 + 口径 + 日期 + 链接。
- B 档必须保留限定词（「预估」「起」「搭配购」），不能去掉前缀单独报数。
- C 档只能答「需官方询价 / 已下架」，禁止估算，也不得用相近型号或消费款价格代填。
- 价格快照日期 2026-10-17，金额随地区、账号、库存与活动变化，下单前必须在结算页复核。

替换真实知识库
打开 index.html，找到 knowledgeBase 对象，替换以下数据：
- products：产品名、系统、处理器、屏幕、适配关键词、卖点、来源路径
- forbidden：合规禁用词
- scenarios：场景卡标签
价格数据在 priceReference 对象（snapshot / records / groups / products 三档数组）。
情境题库在 scenarioRows() 函数里，按 cat 字段分组，改文案直接改这里。

当前版本说明
- 零依赖单文件前端，全部 HTML/CSS/JS 在 index.html，可直接用 file:// 打开。
- 文案与回答基于本地规则匹配，不依赖外部接口，避免现场网络或密钥问题。
- 咨询中心可选接入自己的 OpenAI 兼容接口；密钥只存当前页面内存，刷新即清除，
  不写入 localStorage。不配置就用本地资料回答。
- 价格不自动带出：必须销售手工录价并逐项确认，避免「拿 A 的价格报 B 的机型」。
- 介绍卡与 SVG/PNG 导出均由本页本地生成，不加载外部图片或字体。
- 工作留档存在浏览器 localStorage 的 pc-agent-worklogs 键下，只在这台电脑的这个
  浏览器里。换机器、清缓存、无痕窗口都不保留，重要的内容记得复制出来另存。
  旧版单条归档（pc-agent-handoff）会在首次打开时自动转成一条留档，不丢数据。
